Upload documents to teach an agent what isn't on your website.

## Upload files

:::steps
1. Open **Knowledge**, press **Add knowledge** and choose **Files**.
2. Drop files onto the window, or press **Choose files**. You can add several at once.
3. Press **Add file** (or **Add 3 files** when you picked several). Each file becomes its own source.
:::

@clip knowledge-files | Upload a PDF. It's ready to answer from in a few seconds.

| Supported | Limit |
| --- | --- |
| PDF, DOCX, TXT, MD and CSV | Up to 20 MB per file |

Replybek reads the text of each file, splits it into passages and indexes them. When the readiness says **Ready**, the agent can quote it.

## Tips for good documents

- **Text, not pictures.** A scanned page without a text layer has nothing to read. Export documents to PDF from Word or Google Docs instead of scanning them.
- **Clear headings.** Headings like "Gift cards" or "Warranty claims" help the agent find the right passage.
- **One topic per file** is easier to keep current than one giant document.

## Update a file

Files don't change on their own. When a document changes, remove the old source and upload the new version. For content that changes often, a [website](websites) source with automatic re-sync is easier.
