Open **Website widget** in the sidebar and pick the agent at the top. The preview on the right shows your changes as you make them. Press **Save changes** when you're done. Visitors see the new look the next time the widget loads.

@clip widget-customize | Pick a colour, upload a logo, set the name and welcome, then save.

## What you can change

| Setting | What it does |
| --- | --- |
| Accent colour | The header, the chat button and the visitor's messages. Pick a preset or type any hex colour, like `#1f3d36`. Choose a dark shade so the white text stays readable. |
| Logo | Shown in the chat header. Square images look best. PNG, JPG, SVG, WebP, GIF or ICO, up to 200 KB. Without a logo, the header shows your initials. |
| Display name | The name at the top of the chat. Leave it empty to use your workspace name. |
| Welcome message | The first message visitors see. It's the same setting as the welcome message in the [Playground](playground). |
| Show "Powered by Replybek" | The small line in the chat footer. |

:::note Removing the branding
"Powered by Replybek" stays on the Starter plan. On Growth and Business you can turn it off. See [Plans and billing](plans-and-billing).
:::

## Welcome messages in several languages

There is one welcome message per agent, shown to every visitor. If your customers speak different languages, write it in two, for example "Salom! Hi! How can I help?". The agent answers each customer in their own language anyway. See [Widget languages](widget-languages).

## The agent's name

Visitors see the agent's name under the display name, like "Northstar Help · AI agent". Change it in the [Playground](playground), under **Agent name**.
